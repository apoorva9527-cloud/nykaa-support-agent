# Order Cancellation Policy

> Demo policy created only for the Nykaa Support Agent project. It does not represent Nykaa's real policy.

## Cancellation eligibility

- Orders in the **Placed** status can normally be cancelled.
- Orders already **Shipped** cannot be cancelled through the standard cancellation flow.
- Delivered orders must follow the return process instead.
- Some promotional, customised, or non-returnable items may not be eligible for cancellation.

## Cancellation process

1. Customer provides the order ID.
2. Support verifies the current order status.
3. If eligible, the order is cancelled.
4. For prepaid orders, the refund is initiated to the original payment method.
5. The customer receives a cancellation confirmation.

## Support guidance

- Never promise cancellation before checking the order status.
- If shipment has started, explain the return or refusal-at-delivery option when applicable.
