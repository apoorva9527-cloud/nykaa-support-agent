# Reverse Pickup Policy

> Demo policy created only for the Nykaa Support Agent project. It does not represent Nykaa's real policy.

## Eligibility

- Reverse pickup is available only for items that are eligible for return or exchange.
- The return request must be raised within the category-specific return window.
- The item must be unused, with original packaging, tags, and invoice where applicable.
- Pickup availability depends on the customer's postal-code serviceability.

## Pickup process

1. The customer raises a return request with the order ID.
2. The support system checks return eligibility.
3. A pickup request is created for the registered delivery address.
4. The delivery partner attempts pickup within 2 to 4 business days.
5. After quality checks, the refund or exchange process begins.

## Support guidance

- If pickup is unavailable for a postal code, ask the customer to use the self-shipping option.
- If a pickup attempt fails, confirm the address and schedule another attempt.
