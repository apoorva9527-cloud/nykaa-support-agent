# Size Exchange Policy

> Demo policy created only for the Nykaa Support Agent project. It does not represent Nykaa's real policy.

## Eligibility

- Size exchange is available for eligible apparel and footwear items.
- A request must be raised within 15 days of delivery.
- The item must be unused, unwashed, and have original tags attached.
- The requested replacement size must be in stock.

## Exchange process

1. Customer submits the exchange request with the order ID.
2. The item is checked for exchange eligibility.
3. Reverse pickup is arranged where serviceable.
4. The replacement item is dispatched after the original item passes quality checks.

## Support guidance

- Check the product category, delivery date, and requested size.
- If the new size is unavailable, offer a return and refund option when eligible.
- Opened beauty products and electronics are not eligible for size exchange.
