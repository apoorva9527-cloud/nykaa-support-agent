# Return Policy

> Demo policy created only for the Nykaa Support Agent project. It does not represent Nykaa's real policy.

## Return window by category

| Category | Return window |
|---|---:|
| Beauty | 7 days, only if unopened and unused |
| Apparel | 15 days, with original tags attached |
| Footwear | 15 days, unused and in original packaging |
| Home | 10 days, unused and undamaged |
| Electronics | 7 days, only for eligible items |

## General conditions

- The item must be in its original condition.
- Original packaging, invoice, and accessories must be available.
- Opened beauty products are not eligible for return.
- Items marked as non-returnable cannot be returned.
- If an item arrives damaged or incorrect, the customer should report it within 48 hours of delivery.
